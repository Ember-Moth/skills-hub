# 场景模板（按需调用的具体写作模板）

> 七个基础场景模板 + 五个特殊场景模板。每个模板都是可直接套用的写作骨架。

---

## 模板 A：宏大启幕

### 适用场景
- 全书序幕
- 三部曲开端
- 重要章节的开场

### 结构

```
[广角环境扫描] → [一个运动中的主体] → [感官细节] → [忽然从宏大收束到一个人物]
```

### 范例（黑月之潮·楔子）

> 黑蛇直起身体向泛着银光的冰海尽头眺望，那里有鲸鱼突破冰面喷出冲天的水柱。黑蛇发出无声的咆哮，对着虚空吐出幽蓝色的气息。
>
> 它又来了，总在月圆之夜。
>
> 雷娜塔趴在禁闭室的铁门上往外张望，瑟瑟发抖……

### 应用：写一段历史小说开场

**场景**：1911 年辛亥革命前夕

**结构套用**：

> 黄鹤楼在浓雾里只剩一个影子，江上的船都停了。
>
> 起义的火药味，顺着汉水飘过来。
>
> 那个十七岁的少年站在岸边，看着对岸的灯火渐渐亮起。

## 模板 B：战斗场景

### 适用场景
- 屠龙战斗
- 任何对峙/战争场景
- 体育竞技

### 结构

```
[简短有力的动作句] → [意象化的力量描写] → [插入内心感受/回忆闪回] → [回到动作，速率加快] → [定格于一个决定性瞬间] → [收束于一个意象]
```

### 范例（黑月之潮·楚子航 vs 龙）

> 楚子航踏破暴风雨而来，狂风中风衣翻飞，仿佛战旗。他正仰望高空，瞳孔流淌着熔铁般的颜色。他没有必要潜行，他是皇，绝无仅有的皇，只需以绝对的暴力碾压过去就好了。

### 应用：写一段武侠对决

**场景**：两位剑客的对决

**结构套用**：

> 剑光亮起时，叶孤城已经动了。
>
> 剑光像一弯新月，划破夜色。
>
> （回忆：西门吹雪曾经告诉过他——"真正的剑客，从不主动出手"）
>
> 剑光骤然加速！
>
> 定格——叶孤城的剑停在西门吹雪咽喉前一寸。
>
> 收束——那弯新月般的剑光，已经消散在夜色里。

## 模板 C：情感独处

### 适用场景
- 角色独处的场景
- 情感反思
- 创伤回忆

### 结构

```
[安静的环境 + 天气] → [一个微不足道的小动作] → [回忆或内心独白] → [一个意象锚定情绪] → [留白结尾]
```

### 范例（悼亡者之瞳·序幕）

> 教室里只剩下他一个人，灯光惨白，而外面黑得像是深夜。
>
> 他掏出手机，把免提打开，放在桌上，默默地看着它。
>
> 接下来的几十秒里他一直在数自己的心跳，咚咚……咚咚……咚咚……
>
> "好呢好呢没问题！在学校等着，我一会儿就到！"短信回复。

### 应用：写一段失去亲人的独处

**结构套用**：

> 房子里很安静，连钟摆的声音都显得很响。
>
> 他坐在父亲坐过的椅子上，试着调整到父亲习惯的高度。
>
> 桌面上的收音机还开着，播着父亲最爱听的评书。
>
> 他没有关。

## 模板 D：对话交锋

### 适用场景
- 反派对峙
- 谈判
- 任何高密度的对话场景

### 结构

```
[一个动作或视觉细节开场] → [表面对话（日常/寒暄）] → [对话逐渐深入] → [一句直接刺穿伪装的话] → [沉默/动作回应]
```

### 范例（黑月之潮·橘政宗 vs 王将）

> "我们打个赌吧，看谁是这场战役的赢家。"
> "赌注呢？"
> "赌注是，如果我们再死一次，就做一个朋友。"

### 应用：写一段职场谈判

**场景**：两个商人谈判

**结构套用**：

> 两人面对面坐下。茶杯里的热气袅袅升起。
>
> "老李啊，好久不见。"
> "是啊，老张。还是这么精神。"
>
> （寒暄完毕）
>
> "听说你最近在收购我的公司？"
> "老李误会了。我只是觉得你的公司有更好的归宿。"
>
> （沉默）
>
> 茶杯里的热气散尽。

## 模板 E：人物初登场

### 适用场景
- 新角色第一次出场
- 重要配角介绍

### 结构

```
[环境制造期待] → [入场动作] → [外观特写] → [暗示性格的小细节] → [其他人反应的侧面烘托]
```

### 范例（黑月之潮·赫尔佐格第一次登场）

> 赫尔佐格从黑暗里走出来，紫色领巾在月光下闪着冷光。
>
> 他走得并不快，每一步都很坚定，肩背挺拔，像个年轻人。
>
> "诸位先生，晚上好。"
>
> 周围的客人都沉默了——这个人身上有一种让人不敢直视的威严。

### 应用：写一段侦探登场

**结构套用**：

> 警车停在案发现场，所有人都让出一条路。
>
> 那个人从车里走出来，外套的下摆在风中微微扬起。
>
> 他戴着一双白手套，不是因为讲究，是因为不想留下任何指纹。
>
> "现场有没有动过？"
> 助手摇摇头。
>
> 他蹲下来，看着地上的血迹。
>
> 旁边的刑警都屏住了呼吸——他只要出现，就没有破不了的案子。

## 模板 F：追忆/念旧

### 适用场景
- 角色回忆过去
- 创伤场景的再现
- 怀旧段落

### 结构

```
[当下的小物件或感官触发] → [记忆闪回] → [过去的场景重新浮现] → [回到当下，物是人非的落差] → [一句克制的话收束]
```

### 范例（悼亡者之瞳·楚子航追忆）

> 看到校园里的一辆迈巴赫，楚子航忽然想起——
>
> （回忆父亲开车来接他的雨夜）
>
> 他转过头去，不看了。

### 应用：写一段分手后的回忆

**结构套用**：

> 在街角咖啡店，她又点了一杯他爱喝的焦糖玛奇朵。
>
> （回忆：那年夏天，他们第一次在这家店约会）
>
> （回忆：他教她怎么用吸管喝奶泡，说这样不会烫）
>
> 她端起咖啡，喝了一口。
>
> 奶泡已经凉了。

---

## 模板 G：诀别/告别

### 适用场景
- 死亡告别
- 久别重逢后的分离
- 永久的别离

### 结构

```
[一个正在远去的人/物] → [静止的观察者] → [风/雨/月等自然元素] → [一句没说出口的话] → [以意象收束]
```

### 范例（黑月之潮·绘梨衣之死）

> 尾声：路明非走出高天原，樱花爆竹碎片像是飞雪那样席卷整个大厅，模糊了所有人的视线。
>
> 他走到直升机旁，没有回头。
>
> "Sakura最好了。"

### 应用：写一段父子诀别

**结构套用**：

> 火车启动，父亲的身影越来越小。
>
> 他站在月台上，没有挥手。
>
> 风从隧道的方向吹过来，带着煤烟味。
>
> 他想说什么，但火车已经消失在了远方。
>
> 风吹动他空荡荡的衣袖。

## 特殊场景模板 1：死亡

### 结构

```
[生前的最后一个动作] → [死亡的瞬间] → [其他人的反应（克制）] → [一个遗物] → [留白]
```

### 应用：写一段英雄之死

> 他把剑插在地上，单膝跪下。
>
> 血从嘴角流下来。
>
> 周围的人都停下了动作——没有人愿意对倒下的人动手。
>
> 他从怀里掏出一封信，递给身边的年轻人。
>
> "把它交给……"
>
> 他没有说完。

---

## 特殊场景模板 2：重逢

### 结构

```
[时空的跨越（多年后）] → [认出对方的瞬间] → [克制] → [一个细节泄露情感] → [对话的开始]
```

### 应用：写一段多年后的同学聚会

> 二十年后，教室还是那个教室，桌子还是那些桌子。
>
> 她推门进来的时候，他正低头看手机。
>
> "老张？"
>
> 他抬起头，眼睛一下子湿了。
>
> "老李……你怎么……"

---

## 特殊场景模板 3：首次心动

### 结构

```
[一个普通的场景] → [一个不普通的细节] → [自己都没意识到的心动] → [外部的打断] → [留下回味]
```

### 应用：写一段少年的心动

> 那是个普通的下午，他在图书馆自习。
>
> 她走过来，问他借一支笔。
>
> 他抬起头，递过去。
>
> 她的眼睛很亮，睫毛很长。
>
> 他愣了一秒——这是他第一次注意到她。
>
> "谢谢。"她笑了一下，转身走了。
>
> 他看着她走远，忽然觉得这支笔是她从他这里"借走"了什么。

---

## 特殊场景模板 4：失败

### 结构

```
[所有的努力] → [关键的失败] → [跌入谷底] → [短暂的沉默] → [一个重建的开始]
```

### 应用：写一段考试失败

> 他检查了五遍答案，每道题都认真核对过。
>
> 成绩出来的那一刻，他的手在抖。
>
> 87 分。差 3 分。
>
> 他坐在教室里，没有立刻回家。
>
> 天黑了，他终于站起来。
>
> 明天还要早起。

---

## 特殊场景模板 5：真相揭示

### 结构

```
[伏笔的累积] → [揭示的瞬间] → [角色的反应（克制）] → [沉默] → [一个新的开始]
```

### 应用：写一段爱情中的真相揭示

> 她终于承认了，她一直在骗他。
>
> 她不是为了钱才和他在一起的。
>
> 她是为了离他近一点。
>
> 他看着她，眼泪忽然就下来了。
>
> 他抱住她。
>
> 窗外的雪落了一整夜。

---

## 综合应用：七个模板的组合

### 范例：一个完整的章节结构

**章节开头**：模板 A（宏大启幕）
**章节中段**：模板 B（战斗）+ 模板 D（对话交锋）
**章节高潮**：模板 C（情感独处）
**章节收束**：模板 G（诀别/告别）

**节奏设计**：
- 加速：战斗
- 减速：独处
- 切换：对峙
- 收束：告别

---

## 模板调用的格式建议

调用时，请提供：

1. **场景类型**：七种模板之一
2. **场景功能**：推动情节 / 塑造人物 / 揭示主题
3. **场景的情感基调**：震撼 / 悲怆 / 喜悦 / 悬念 / 释然
4. **字数要求**：300 字片段 / 1000 字场景 / 完整一章
5. **特殊要求**：金句、意象、对话风格

skill 会根据模板 + 七铁律生成场景。
