## 已知限制

1. **章节深度不足**：补写章节字数通常只有原文的 49-65%，原因是在无原文长度参照时倾向安全篇幅
2. **句长比例不稳定**：某些场景（尤其情感简短的）长句比可能跌至 12%
3. **金句原创性**：在没有原文参照时，从零创作同等质量金句的难度极高——这是"创造力"层面的差距
4. **需要全书铺垫的情感积累**：如"七万字铺垫后的那一句话"，无法被模块再现
