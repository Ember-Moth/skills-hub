# 应用示例：从零到江南式

> 三个完整的应用示例，展示如何用这个 skill 从一个简单的题材构思，演化到一段江南式的文学片段。

---

## 示例 1：把"朋友离开"写成江南式

### 用户原始需求
> "我想写一段朋友要离开这座城市，我去机场送他的场景。"

### 应用过程

**步骤 1：确定结构骨架**
- 场景类型：模板 G（诀别/告别）
- 场景功能：揭示主角的成熟
- 情感基调：克制 + 悲伤 + 释怀

**步骤 2：构建人物**
- 主角：外向但此刻压抑
- 朋友：理性、要远行
- 内在冲突：想说"别走"但知道不能

**步骤 3：选择场景模板**
模板 G + 模板 F（追忆）的混合

**步骤 4：填充修辞**

### 输出（江南式）

他站在出发大厅的玻璃前，看着雨水顺着玻璃流下来。

航班还有四十分钟起飞，他还没来。

广播里播报着某地起飞的航班抵达信息，每个字都听得很清楚，但又不记得任何一个。

他想起三年前，他们一起在这座城市下的第一场雪。那时候他们刚毕业，租在同一个房间里，每天为吃泡面还是吃挂面争吵。他教他怎么煮挂面要先过一遍凉水，他教他泡面要加一个蛋才好吃。

现在他要走了，去另一个城市，去做另一份工作，去过另一种生活。

他想起他昨天说："其实我也不想去，但那边给的薪水是这边的两倍。"说这话的时候，他在笑，像是在说一件值得庆祝的事。

他没有劝他留下。

他知道劝没有用。成年人做的决定，都是算过账的。

他的航班开始登机了。

广播里传来一个温柔的女声："前往巴黎的旅客请注意，您乘坐的航班即将起飞……"

巴黎。

他忽然想起，他们以前约定过，要一起去巴黎看埃菲尔铁塔。

他们没有去。

现在他一个人去了。

玻璃上映出他自己的脸。他发现自己的眼眶有点红，但他没有哭。

手机响了，是他发来的消息：

"走了，别想我。"

他回了一个字：

"嗯。"

他把手机放回口袋，端起那杯已经凉了的咖啡，一饮而尽。

窗外的雨还在下。

---

### 输出（直白版）的对比

**直白版**：
> 朋友要去别的城市工作了，我很舍不得。我们在机场告别。我很伤心，但他必须走。我们约定以后还会再见的。

---

### 改写要点分析

1. **不写"我很舍不得"**——写"航班还有四十分钟起飞，他还没来"（延迟出场）
2. **不写"我们约定以后还会再见的"**——写"他们没有去。现在他一个人去了"（未兑现的约定）
3. **不写"我很伤心"**——写"眼眶有点红，但他没有哭"（克制的悲伤）
4. **不写"我们回忆过去"**——通过泡面和挂面的小细节
5. **不写"他必须走"**——通过"算过账的"和"薪水是两倍"
6. **用未完成的意象收束**——"窗外的雨还在下"

## 示例 2：把"反派登场"写成江南式

### 用户原始需求
> "我想写一个反派第一次登场，要让读者感到他很危险，但又说不清为什么危险。"

### 应用过程

**步骤 1：确定结构骨架**
- 场景类型：模板 E（人物初登场）+ 模板 D（对话交锋）
- 场景功能：揭示反派的优雅与危险
- 情感基调：压抑 + 不安

**步骤 2：构建人物**
- 反派：表层身份是"学者"，中层身份是"操纵者"，底层身份是"灭绝者"
- 双声人格：外在的温柔 vs 内在的冷酷
- 台词谱：诗意 + 古典文学引用

**步骤 3：场景设计**
- 地点：茶馆或书房
- 时间：黄昏
- 配角：主角 + 几个"应该"信任反派的人

### 输出（江南式）

那家茶馆在城市的尽头，门脸很小，但走进去却很深。

傍晚的阳光从窗户里斜斜地照进来，把店里的灰尘都染成了金色。

他已经在那里等了很久了。

主角推门进去时，铃铛轻轻响了一声。那个人从茶盏后面抬起头，微笑。

"你来了。"

他穿着一件灰色的亚麻衬衫，领口系着一条紫色的小领巾。头发整齐地梳向脑后，没有任何一根凌乱。他看起来像是一个大学教授，或者一个退休的政府官员。

"请坐。"他指了指对面的椅子，"我给你倒茶。"

主角在他对面坐下。桌上已经摆好了一套茶具，是民国的老物件，包浆温润。

"你一定想问，"他一边倒茶一边说，"为什么我会在这里等你。"

"是的。"主角说。

"因为我一直在等你。"

他把茶杯推到主角面前。茶汤清澈，带着淡淡的焦糖香。

主角接过茶杯，但没有喝。

"这茶不错。"他说。

"是武夷山的大红袍。去年的产量很少，今年更少。"他说，"好东西永远都是这样——你以为是偶然得到的，其实背后都有代价。"

主角看着他，忽然感到一阵寒意。

不是因为他说了什么可怕的话。

而是因为他在说"好东西永远都是这样"的时候，眼睛里闪着一种说不清的光——像是一个园丁在欣赏自己刚刚修剪过的草坪，草坪上躺着几株被修剪掉的残花。

主角的手开始微微发抖。

"你在害怕。"他说，微笑着。

"没有。"

"你在害怕。"他又说了一遍，"我能闻到。"

他端起自己那杯茶，轻轻抿了一口。

"但这没关系。"他说，"害怕的人活得最长。"

主角离开了茶馆，走出很远才发现，自己后背的衣服已经湿透了。

他回头看了一眼那家茶馆。

茶馆的灯已经灭了。

但那个人还坐在那里——主角透过窗户看到他，正对着自己离开的方向，微微举起茶杯，像是在敬他。

---

### 反派设计的三层结构

| 层 | 揭示 | 读者反应 |
|---|------|---------|
| 表层 | 优雅的教授 | 信任 |
| 中层 | "好东西背后都有代价" + 修剪草坪的眼神 | 怀疑 |
| 底层 | 主角的衣服湿透了 / 茶馆的灯灭了 | 恐惧 |

## 示例 3：把"暗恋"写成江南式

### 用户原始需求
> "我想写一段主角暗恋同班同学很多年，但从来没有说出口的场景。"

### 应用过程

**步骤 1：确定结构骨架**
- 场景类型：模板 F（追忆/念旧）
- 场景功能：揭示暗恋的苦涩与美好
- 情感基调：克制 + 温柔 + 释怀

**步骤 2：构建人物**
- 主角：双声人格——表面的沉默 vs 内在的汹涌
- 暗恋对象：一个普通的同学

**步骤 3：场景设计**
- 地点：教室
- 时间：毕业多年后的同学聚会
- 触发物：一个细节（座位 / 笔记 / 某个动作）

### 输出（江南式）

同学聚会定在那家老餐厅，他到的时候，她已经在了。

她坐在靠窗的位置，阳光从她背后照过来，把她的轮廓镶了一圈金边。

他恍惚了一下——二十年前，她也坐在靠窗的位置。那时候教室的窗户没有这么大，光也没有这么亮，但她总是坐在那里，背挺得很直，看黑板。

他走过去，坐在她对面。

"好久不见。"他说。

"是啊。"她说，"你一点都没变。"

"你也是。"

他发现她在骗他——她的眼角有了细纹，发际线也有一点白。但他没有揭穿，因为这句话本身，就已经让他很感动了。

他们开始聊工作、聊生活、聊孩子。她有两个孩子，大的已经上初中了。

"像你。"他说。

"哪里像我。"她笑了，"他爸说我小时候很安静，他就是个话痨。"

他听着她说话，忽然想起很多事。

想起初二那年的元旦晚会，她表演了一个节目，唱了一首歌。他坐在最后一排，看着她，觉得她像一颗星星。

想起初三那年的运动会，她跑 800 米，他在终点等她。她跑过来时，他递给她一瓶水。她笑着说谢谢，然后跑向了别人。

想起高一那年的某个晚自习，他写了一张纸条，写了很久很久，最后还是没有交给她。他把纸条夹在了一本小说里，那本小说他到现在还留着。

想起高三毕业那天，他本来想跟她合影，但因为人太多，他一直没找到机会。

后来，他们上了不同的大学，再后来，他们有了各自的生活。

现在，他们坐在老餐厅里，聊着各自的孩子。

"你最近怎么样？"他问。

"挺好的。"她说，"你呢？"

"也挺好的。"

她端起茶杯，喝了一口。

他忽然很想告诉她——他曾经很喜欢她，喜欢了很多年。但他没有说。

不是因为还喜欢。

而是因为说出来也不会改变任何事。

她放下茶杯，看着窗外。

"今天的天气真好。"她说。

"是啊。"他说。

他们又聊了一会儿。

离开的时候，他们在餐厅门口告别。她向他挥手，他向她挥手。

他转身走开，走了几步，忽然停下来。

他回过头，看着她离去的背影。

她已经走出了很远。

他忽然想起那张纸条——夹在一本小说里，他到现在还留着。

他不知道她会不会知道。

他也没有打算告诉她。

他只是忽然觉得，年轻的时候，他好像欠了她一句话。

但已经过了该说这句话的时候了。

他笑了笑，转身走开。

夕阳把他的影子拉得很长。

---

### 暗恋场景的设计要点

1. **不写"我喜欢她很久了"**——通过具体的回忆细节（元旦晚会、800米、纸条）
2. **不写"我没说出口"**——通过"他本来想跟她合影，但因为人太多"
3. **不写"我已经不爱她了"**——通过"说出来也不会改变任何事"
4. **不写"我们错过了"**——通过"已经过了该说这句话的时候了"
5. **用未完成的意象收束**——"夕阳把他的影子拉得很长"

## 示例 4：把"战斗前"写成江南式

### 用户原始需求
> "我想写一段战斗前的紧张感，角色即将面对不可能战胜的敌人。"

### 输出（江南式）

他在悬崖边停下脚步，往下看。

下面是万丈深渊，云雾在脚下翻涌。

远处有一座黑色的城堡，孤零零地立在群山之巅，像一个王朝的墓碑。

"就是那里。"身后的人说。

他没有回答。

他知道。

他低头看了看自己的剑——剑刃上有三道缺口，是昨天战斗留下的。剑柄上缠着的布已经磨破了，露出里面暗红色的血渍。

他抬起头，看着那座城堡。

风从山谷里吹上来，带着一股腐烂的味道——是死亡的味道。

"你知道的。"身后的人说，"你没有胜算。"

"我知道。"他说。

"那你为什么还要去？"

他没有立刻回答。

他看着那座城堡，又看了看天——太阳正在西沉，把整片天空染成了血红色。

他忽然想起一些事。

想起师父在他出发前递给他的那杯酒。师父没有说话，只是看着他，把酒一饮而尽。

想起师妹在门口追着他跑了几步，把一个护身符塞进他手里。她说，师兄，你一定要回来。

想起很多年前，他第一次握住剑的时候，师父问过他一句话——

"你为什么要练剑？"

他当时回答："为了保护想保护的人。"

师父笑了笑，没有再说什么。

现在师父已经死了。

师妹也已经嫁给了别人。

想保护的人，都不在了。

他忽然明白了——他练剑，从来不是为了保护谁。

他练剑，是为了在必须挥剑的时候，能够挥出去。

"走吧。"他说。

身后的人没有动。

"你疯了吗？"他说，"你一个人去，就是送死。"

"我知道。"他说，"但我必须去。"

"为什么？"

他回头，看着身后的人。

"因为如果我不去，明年的今天，就会有很多人死在那座城堡里。"

"那和你有什么关系？"

"没有关系。"

他转回头，看着那座城堡。

"但我会内疚。"

他没有再说什么，向前走去。

身后的人看着他走远，影子在夕阳下越拉越长。

"你真的会死。"身后的人喊道。

"我知道。"他头也不回地说。

风把他的声音吹散在山谷里。

---

### 战斗前场景的设计要点

1. **不写"我很紧张"**——通过悬崖、深渊、腐烂的味道
2. **不写"敌人很强"**——通过三道缺口和破旧的剑柄
3. **不写"我必须去"**——通过师父和师妹的回忆
4. **不写"我可能会死"**——通过身后的人反复说
5. **用对话揭示角色的内在**——"我会内疚"
6. **用影子拉长收束**——视觉化的告别

## 示例 5：把"亲子冲突"写成江南式

### 用户原始需求
> "我想写一段父亲和成年儿子之间的矛盾——儿子不愿意继承家业。"

### 输出（江南式）

父亲把茶杯放在桌上，茶杯发出轻轻的响声。

父子两人坐在客厅里，中间隔着茶几，谁也没有说话。

客厅里很安静，只有墙上的钟在滴答滴答地响。

"我已经说过了。"儿子先开口，"我不会接手公司。"

"我知道。"父亲说。

"那你为什么还要叫我回来？"

"因为这是规矩。"

儿子忽然笑了。

"规矩。"他说，"你的规矩。"

父亲没有说话。

儿子看着父亲，忽然发现他老了很多——头发已经全白了，脸上也有了老年斑。他的手放在茶杯上，那只手上布满了老年斑和皱纹。

儿子忽然想起小时候——那时候父亲还很年轻，会把他扛在肩膀上，会带他去钓鱼，会在夏天的晚上教他认星星。

后来父亲开始做生意，越来越忙。

再后来，父亲开始教他怎么做生意——怎么跟人握手、怎么跟人喝酒、怎么跟人签合同。

但父亲从来没有教过他——为什么要做生意。

"爸。"儿子说。

"嗯。"

"你快乐吗？"

父亲抬起头，看着儿子。

那是一双看了儿子很多年的眼睛。从儿子出生的那一天起，父亲就开始用这双眼睛看他。看着他会爬、会走、会跑、会说话、会哭、会笑。

但现在，这双眼睛里多了一种东西。

儿子看不懂那是什么。

"快乐？"父亲重复了一遍这两个字。

然后他笑了。

"我已经很久没想过这个问题了。"

儿子也笑了。

他们又沉默了一会儿。

"茶凉了。"儿子说。

"嗯。"父亲说。

"我去换一壶。"

"不用。"父亲说，"凉茶也很好。"

儿子看着父亲，忽然明白了什么。

父亲想要的，从来不是他接手公司。

父亲想要的，是他回家。

---

### 亲子冲突场景的设计要点

1. **不写"我不要你的公司"**——通过对话的克制
2. **不写"你为什么不理解我"**——通过"快乐吗"这个反问
3. **不写"你变了"**——通过"已经很久没想过这个问题了"
4. **不写"他很孤独"**——通过"凉茶也很好"
5. **不写"父亲想要的是儿子回家"**——通过最后一句揭示
6. **用细节泄露情感**——老年斑、白发、钟的滴答声

---

## 综合原则

江南式的写作有以下核心原则：

### 1. 永远不要直说情感

| 直白 | 江南式 |
|------|--------|
| 他很悲伤 | 他发现自己的眼眶有点红，但他没有哭 |
| 她很孤独 | 她坐在靠窗的位置，阳光从她背后照过来 |
| 他很紧张 | 剑刃上有三道缺口，是昨天战斗留下的 |
| 父亲很孤独 | 他想要的，是他回家 |

### 2. 永远用物象替代心理

| 抽象 | 物象 |
|------|------|
| 时间流逝 | 钟的滴答声 |
| 记忆 | 一本夹着纸条的小说 |
| 父亲的衰老 | 老年斑、白发 |
| 死亡的味道 | 腐烂的味道 |

### 3. 永远用对话揭示内在

| 表面对话 | 内在 |
|---------|------|
| "你快乐吗？" | 我想知道你过得好不好 |
| "凉茶也很好。" | 我习惯了孤独 |
| "我会内疚。" | 我怕的不是死亡，是良心不安 |
| "你知道的。" | 我知道我没胜算 |

### 4. 永远用未完成的意象收束

| 直白收束 | 江南式收束 |
|---------|----------|
| 他离开了 | 影子在夕阳下越拉越长 |
| 她走了 | 她已经走出了很远 |
| 他很孤独 | 凉茶也很好 |
| 他永远不会忘记 | 那本小说他到现在还留着 |

### 5. 永远保持克制

江南从不写"他哭着说""他笑着说""他激动地说"——这些副词都是廉价的。

他写：
- "他的声音很平静。"
- "他说这话的时候在笑。"
- "他说完这句话就转身走了。"

让读者自己判断情感。
