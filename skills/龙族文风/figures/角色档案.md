# 主要人物档案

> 江南笔下的核心人物档案。每个角色都有完整的"写作卡片"，包括：内在冲突、双声人格、台词谱、弧光、关键场景、可复用元素。

---

## 路明非（主角）

### 基本档案
- **外在身份**：S 级混血种、卡塞尔学院学员
- **真实身份**：路鸣泽的哥哥 / 白色皇帝候选
- **标志性物品**：橡皮鸭子、连帽衫、二手笔记本
- **标志性场景**：教室、网吧、深海、高天原

### 内在冲突
**衰仔外表 vs 沉睡的龙王血统**
**内心 OS vs 说出口的话**

### 双声人格

| 维度 | 外在声音 | 内在声音 |
|------|---------|---------|
| 语调 | 吐槽、自嘲、烂话 | 哲学、预言、命令 |
| 语言 | "你妹啊""TNND""废柴" | "权力是让人着迷的东西" |
| 行动 | 退缩、装死 | 不由自主地服从 |
| 自我认知 | 废柴 | 隐藏着渴望 |

### 台词谱
- **词汇**：网络俚语 + 自我贬抑
- **句式**：长吐槽 + 短烂话
- **话题**：游戏、动漫、自己的失败、对诺诺的暗恋
- **标志性节奏**：先自嘲 → 然后正经 → 然后继续自嘲

### 弧光

| 阶段 | 外在声音占比 | 内在声音占比 |
|------|------------|------------|
| 第一卷序幕 | 90% | 10% |
| 第一卷前五幕 | 80% | 20% |
| 第一卷第六幕 | 50% | 50% |
| 第一卷第十幕 | 10% | 90% |
| 第二卷整体 | 70% | 30% |
| 第三卷整体 | 60% | 40% |
| 尾声 | 90% | 10% |

### 关键场景
- 序幕：梦中白衣少年
- 第一卷：被诺诺从放映厅捞出来
- 第一卷：3E 考试画第九张答卷
- 第一卷：与路鸣泽缔结契约
- 第二卷：教楚子航追女孩（实为最大反面教材）
- 第三卷：与绘梨衣的七天
- 第三卷：天谴战斗中

### 可复用元素
1. **吐槽式开场**：任何场景都可以用吐槽建立
2. **双声切换**：内心 OS 与说出口的话的对比
3. **橡皮鸭子**：作为思念的寄托物
4. **75% 的生命**：作为代价的隐喻
5. **"something for nothing"**：作为契约的核心

## 楚子航

### 基本档案
- **外在身份**：A 级混血种、卡塞尔学院学员
- **真实身份**：楚天骄之子、奥丁烙印持有者
- **标志性物品**：村雨（父亲的剑）、君焰
- **标志性场景**：仕兰中学的雨夜、高架路、战场

### 内在冲突
**失去父亲的儿子 vs 永远不表达软弱的战士**

### 双声人格

| 维度 | 外在声音 | 内在声音 |
|------|---------|---------|
| 语调 | 冷、克制、简洁 | 悲痛、怀念、挣扎 |
| 语言 | 短句、动作化（"动了""不要""走了"） | 长句、哲理、回忆 |
| 行动 | 进攻、杀戮 | 在父亲幻觉中获得平静 |
| 自我认知 | 战士 | 永远是那个站在高架路上的男孩 |

### 台词谱
- **词汇**：克制、动作化
- **句式**：超短句，常以动词结尾
- **话题**：父亲、训练、剑、牛奶
- **标志性节奏**：沉默中插一句关键判断

### 弧光
- 序幕：雨夜失去父亲
- 第一卷：成为 A 级学员
- 第二卷：寻找父亲 / 爱上夏弥
- 第二卷：夏弥真实身份揭示
- 第二卷：在尼伯龙根中失去夏弥

### 关键场景
- 序幕：雨夜等待父亲
- 第二卷：与夏弥的约会
- 第二卷：在尼伯龙根中战斗
- 第二卷：抱着垂死的夏弥

### 可复用元素
1. **沉默的角色**：少说话，多用动作
2. **父爱主题**：通过小动作（热牛奶、加半勺糖）展示
3. **冷的表面 + 热的内心**：永远不要直接展示情感
4. **高架路的母题**：每次出现都承载不同的情感
5. **村雨的传承**：作为父子关系的物证

## 赫尔佐格（反派）

### 基本档案
- **外在身份**：纳粹科学家、蛇岐八家的大家长
- **真实身份**：赫尔佐格博士（多重身份）
- **标志性物品**：紫色领巾、白色面具
- **标志性场景**：黑天鹅港、蛇岐八家、猛鬼众

### 三层身份结构

| 层 | 身份 | 功能 |
|---|------|------|
| 表层 | 慈父般的博士 | 掩护真实目的 |
| 中层 | 王将/操纵者 | 推动冲突 |
| 底层 | 灭绝者 | 终极反转 |

### 台词谱
- **词汇**：诗意 + 古典文学引用
- **句式**：宣言式（"那将是我们掀起的第四次战役""我们要……"）
- **话题**：血统进化、神、命运、死亡
- **标志性节奏**：发表格言 → 配以手势 → 笑得温文尔雅

### 关键场景
- 前传：在黑天鹅港作为博士出现
- 第一部：以橘政宗身份出现
- 第三部：以王将身份出现
- 第三部：三层身份揭示
- 第三部：天谴中被杀

### 可复用元素
1. **三层身份的反派**：表层掩护 → 中层操纵 → 底层灭绝
2. **优雅的残酷**：反派不能粗暴
3. **格言式台词**：用诗意语言说恐怖的事
4. **跨卷的揭示**：每卷揭示一层身份

## 总结：江南的"人物设计原则"

江南笔下的人物遵循以下原则：

1. **每个人物都有"内在冲突"**——没有内在冲突的角色 = 工具人
2. **每个人物都有"两个声音"**——外在人格 vs 内在声音
3. **每个人物都有"台词谱"**——词汇、句式、话题的偏好
4. **每个人物都有"弧光"**——双声比例的变化
5. **每个人物都有"关键场景"**——3-5 个情感核心场景
6. **每个人物都有"可复用元素"**——可以迁移到其他作品的特质

**记住**：江南的人物之所以令人难忘，不是因为他们做了什么，而是因为**他们的内在分裂**。

## 应用：为自己的小说设计一个人物

### 步骤

1. **确定内在冲突**（一句话）
2. **设计双声人格**（外在 vs 内在）
3. **设计台词谱**（5 个词汇 + 3 个句式 + 2 个话题）
4. **设计弧光**（开始 vs 结束的双声比例）
5. **设计关键场景**（3-5 个）
6. **设计可复用元素**（3-5 个特质）
