# 江南·文学创作技法体系

> **这不是一个"模仿龙族"的 skill，而是一个从《龙族》全系列（火之晨曦/悼亡者之瞳/哀悼之翼/黑月之潮）四部作品、约 70 万字语料中蒸馏出来的通用文学写作体系。** 它记录了江南作为当代中文奇幻/青春/悲剧类型顶级作家的全部核心技艺——叙事工程、人物构建、修辞工厂、节奏控制、情感操控——并将其提炼为可复用、可迁移、可学习的工艺手册。

---

## 一、技能定位与使用方式

### 这个 skill 是做什么的？

让你在写**任何类型小说**时（不只是奇幻、青春、屠龙同人），能调用江南级别的：

1. **叙事结构工程** —— 序幕怎么埋、章节怎么递、伏笔怎么埋、悬念怎么放
2. **人物构建系统** —— 怎么让一个角色有"两个声音"、怎么用动作和道具代替心理描写、怎么塑造反派
3. **修辞工厂** —— 比喻系统、句式工具、对话潜台词、节奏控制
4. **情感工程** —— 怎么把读者逼哭、怎么制造"差一步"的悲剧、怎么收束全书的情感
5. **场景工程** —— 七种场景模板，从战斗到诀别
6. **史诗架构** —— 多线叙事、POV 切换、多卷铺垫

### 调用方式

```
/江南·文学创作技法体系 [你的写作任务]
```

或更具体的指令，例如：
- "用江南的方法写一段两个老友诀别的场景"
- "分析我这段对话的潜台词密度"
- "按江南的反派三层结构设计一个反派"
- "为我的长篇第一章设计序幕"
- "用物象写心境的方式改写这段心理描写"

### 不做什么

这个 skill 不负责：题材选择、人物创意点子、剧情构思（**这些你提供**）。它负责：**怎么把你想写的东西写得更好**。

## 三、核心写作原则（七铁律）

江南所有作品中贯穿的七条铁律。任何一段文字如果违反其中任何一条，几乎必然失败。

### 铁律一：视觉优先

**每段叙事都必须有画面。** 不是"他在想什么"，而是"他站在哪里，面前是什么光，空气里什么味道"。

- 检查清单：光源 / 主色调 / 一个反复出现的小意象 / 场景的边界

### 铁律二：物象写心境

**绝不直说情感**。写情感时，找一个具体的物理载体——一个动作、一个物品、一个画面——让读者自己感受到。

| 别写 | 要写 |
|------|------|
| 他很孤独 | 他坐在禁闭室里，只有一张孤零零的椅子和光滑的四壁 |
| 她很绝望 | 她像是一朵渐渐干枯的小蘑菇 |
| 他怀念过去 | 偶然在人流如织的街头闻到她惯用的香水味，他在惊悚中下意识地回过头去 |
| 他是个好父亲 | 男人笑得满脸开花，好像一点烦心事都没有似的 |

### 铁律三：双声人格

**主角必须有"内外两个声音"**。路明非脑子里的声音永远比说出口的话精彩一百倍。

- 内心 OS：最口语、最俚俗、最没出息的语言
- 实际说出/做出的：突然间沉默的决绝
- 这种割裂制造了江南全部的喜剧和悲剧张力

### 铁律四：长句蓄能→短句释放

**长句积累能量到顶点时，用一个极短的句子打断，制造冲击。**

> 燎天的烈焰中，城市在哭号，焦黑的人形在火中奔跑，成千上万的箭从天空里坠落，巨大的牌匾燃烧着、翻转着坠落，上面是"白帝"两个字，简直是地狱。
> 城市的正中央，立着一根高杆，孩子被挂在高杆顶上，闭着眼睛，整个城市的火焰，都在灼烧他。
> 像是一场盛大的献祭。

### 铁律五：道具即叙事

**重要的道具必须在首尾两次出现，中间作为情感锚点反复出现。**

| 道具 | 首次出现 | 中段锚点 | 终幕回响 |
|------|---------|---------|---------|
| 橡皮鸭子 | 第一部深海救援 | 路明非每次思念绘梨衣时 | 尾声（未见物，只见念想） |
| 迈巴赫 62 | 序幕楚父接送 | 楚子航每次看到豪华车的反应 | 第十八幕再现于尼伯龙根 |
| 牛奶（加半勺糖） | 序幕父亲叮嘱 | 第一幕日常行为的仪式 | 第二十幕父亲的临终幻觉 |
| 风筝线 | 序幕"风筝线断了" | 路明非送陈雯雯蒲公英 | 蒲公英=同名的台风 |

### 铁律六：伏笔的洋葱剥皮法

**每剥开一层，露出的不是答案，而是更大的谜。** 全书结束时，由这部书开始的问题都得到了回答，但更深层的问题留给了后续。

- 第二层揭示"路明非有龙族血统" → 引出"他为什么能抵御言灵·皇帝？"
- 第三层提出"白王血裔" → 引出"白王血裔意味着什么？"
- 第四层"第九张答卷来自路明非潜意识" → 引出"他的身体里还有什么？"

**规律：每次只揭开上一层问题的一部分，同时引出新的更深层的问题。**

### 铁律七：留白高于表达

**说比不说有力的事情说，不说比说有力的事情不说。**

- 赫尔佐格的三层身份：需要说（核心悬念）
- 路鸣泽的真实身份：不需要说（神秘性即力量）
- 绘梨衣对路明非的感情：说了——但只用日记上的四个字

> "Sakura最好了。"

## 四、写作流程（如何用这个 skill）

### 步骤 1：确定结构骨架

加载 `modules/01-叙事工程.md`，根据你的题材选择对应的结构模板：

- **校园 / 青春成长** → "日常的崩塌"五阶段模式
- **史诗 / 多卷** → "序幕-正文三部-尾声"四段式
- **单元剧** → 单一楔子 + 多幕

### 步骤 2：构建人物

加载 `modules/02-人物构建.md`，按以下顺序：

1. 为主角设计"两个声音"——一个外在人格（读者认同）、一个内在声音（叙事推力）
2. 为每个主要角色建立"人物档案"（参考 `figures/`）
3. 为反派设计"三层结构"——表层身份 / 中层操纵 / 底层真相

### 步骤 3：选择场景模板

加载 `modules/05-场景工程.md` + `templates/`，按场景类型套用：

| 你要写 | 调用 |
|--------|------|
| 序幕/开篇 | 模板 A 宏大启幕 |
| 战斗/高潮 | 模板 B 战斗动力学 |
| 角色独处 | 模板 C 情感独处 |
| 谈判/交锋 | 模板 D 对话交锋 |
| 角色登场 | 模板 E 人物初登场 |
| 回忆/念旧 | 模板 F 追忆场景 |
| 诀别/告别 | 模板 G 诀别场景 |

### 步骤 4：填充修辞与对话

加载 `modules/03-修辞工厂.md`，按七铁律打磨每一个段落：

- 用物象替代心理
- 用双声替代独白
- 用长句蓄能+短句释放
- 用潜台词替代直说

### 步骤 5：节奏控制与情感曲线

加载 `modules/04-情感工程.md` + `modules/09-减法技艺.md`，检查：

- 整体情绪曲线是 W 型吗？
- 这一章在曲线上的位置对吗？
- 是否在合适位置插入了"呼吸段落"？
- 结尾的意象锚定足够有力吗？
- 对话 vs 叙述比例是否合理？（重大情感场景对话 < 10%，牺牲场景 < 5%）

### 步骤 6：意象与符号的布置

加载 `modules/06-意象系统.md`，确保：

- 主题有反复出现的意象锚点（雨、铁轨、月光、樱花、潮水…）
- 每个重要道具至少有 2-3 次出现
- 跨场景的意象呼应

### 步骤 7：减法检查（★核心补强）

加载 `modules/09-减法技艺.md`，尤其在重大情感场景（牺牲/诀别/告白）后必须检查：

- 对话比例是否过高？（牺牲场景对话 < 5%）
- 是否有禁词？（"我爱你""对不起"等）
- 是否有 "未完成的句子" 作为铺垫？
- 长句比例是否达到 15-20%？（若低于 10%，需要补充长句蓄能）
- 关键词是否过度重复？（核心词每千字 > 5 次则需删减）

### 步骤 8：金句与终局

加载 `modules/08-金句美学.md`，检查：

- 这一章是否有一个能被单独拎出来念的金句？
- 金句是否出现在情感顶点而非硬贴？
- 整部作品的尾声是否用"物质的证据"而非叙事的抒情收束？

## 五、通用文学应用：超越奇幻题材

虽然 skill 源自我从奇幻/青春题材的蒸馏，但其核心技艺**可迁移到任何小说类型**：

| 类型 | 调用侧重 |
|------|---------|
| **历史小说** | 01 叙事工程 + 04 情感工程 + 09 减法（史诗感+克制） |
| **校园/青春** | 02 人物构建 + 03 修辞 + 09 减法（双声人格+长句配比）|
| **悬疑/推理** | 01 伏笔系统 + 03 潜台词对话 + 09 减法（留白）|
| **言情** | 04 情感工程 + 06 意象系统 + 08 金句 + 09 减法（禁词）|
| **武侠/仙侠** | 05 场景工程 + 03 修辞工厂 + 09 减法（静默角色）|
| **科幻** | 07 多线叙事 + 01 史诗架构 + 09 减法（节奏控制）|

**最核心可迁移的四条**：
1. 双声人格（任何小说都能让主角有"内外两个声音"）
2. 物象写心境（永远不要直说情感）
3. 长句蓄能→短句释放（基础节奏控制）
4. **减法技艺**（留白比表达更有力 — ★对照实验验证为江南最难学的技艺）

## 六、避免的常见错误

### ❌ 八大致命失误

1. **直白抒情**——"他很悲伤/愤怒/孤独" → 改为物象
2. **冗长心理独白**——让内心戏通过对话和动作泄露
3. **金句硬贴**——金句必须自然浮现在情感顶点，不能强行拔高
4. **网络梗泛滥**——吐槽有语境限制，严肃段落塞段子会破坏氛围
5. **省略号当逗号**——每个"……"都应有情感重量
6. **人物同质化**——主角不会说配角的台词，反派不会像主角那样思考
7. **大场面后无呼吸**——战斗/高潮后必须有安静场景作为情绪缓冲
8. **重大场景滥用对话**——牺牲/诀别场景对话应 < 5%（对照实验验证的最常见错误）

### ✓ 七大加分项

1. 用车的细节塑造身份（Maybach / 兰博基尼 / 玛莎拉蒂）
2. 用食物描写日常的温度（铁板牛肉、温泉蛋、烤面包）
3. 用天气承载情绪（雨、雪、月光、霓虹）
4. 用"瞬间的物理动作"代替心理描写（攥紧、扣胸口、删短信）
5. 用具体到秒的时间标记（"凌晨 3:47"）创造真实感
6. 用"对话中突然插入的沉默"承重
7. 用"无台词的离开"完成一个角色（他没回头）

## 七、特殊应用场景

### 场景 A："我想要一段让人想哭的诀别"

加载：modules/04（情感工程）+ modules/05 模板 G（诀别）+ modules/06（意象系统）

要点：
- 用"正在远去的背影+静止的观察者+风/雨/月"
- 一句没说出口的话（或者写在纸上的话）
- 以意象收束（樱花、北极罂粟、退去的潮水）

### 场景 B："我想要一个让读者震惊的反转"

加载：modules/02 反派三层结构 + modules/03 潜台词对话

要点：
- 在反转前的对话中埋入"用真话说谎"的伏笔
- 反派的每一句话都已经是真相，但读者没注意
- 反转的真正力量不在揭示本身，而在揭示后所有前文的重新阅读

### 场景 C："我要重写自己的第一章"

加载：modules/01 序幕设计 + modules/05 模板 A 宏大启幕

要点：
- 序幕必须完成三件事：主题植入 / 核心关系建立 / 叙事框架暗示
- 用"梦境/幻觉/古远场景"开场，读者不知道时空
- 序幕的最后一句话应当是全书的种子

### 场景 D："我要设计一个有深度的反派"

加载：modules/02 人物构建（反派三层结构）+ figures/角色档案.md（赫尔佐格条目）

要点：
- 反派的每层身份都应有"功能"：表层身份掩护日常，中层操纵推动剧情，底层真相构成终极反转
- 反派的台词必须有"诗意化的残酷"或"优雅的暴力"
- 反派最可怕的不是力量，是**他知道所有人不知道的事**

### 场景 E："我要写一个让人心碎但不说'我爱你'的牺牲场景"

加载：modules/09-减法技艺.md（绝对留白 + 静默角色 + 禁词清单）+ modules/04-情感工程.md（差一步悲剧）

要点：
- 牺牲场景对话比例应 < 5%（对照实验数据）
- 绝对禁词："我爱你""对不起""下辈子"——用动作和眼神代替
- 核心人物（如樱）的台词密度控制在 5 对/章以内
- 用"未完成的句子"在前文铺垫
- 牺牲后用一个遗物/意象收束，**不用叙事的抒情**

## 八、Skill 调用的格式建议

调用此 skill 时，请清晰说明：

1. **场景类型**（序幕 / 战斗 / 情感 / 对话 / 追忆 / 诀别 / 角色登场）
2. **题材与世界观**（校园 / 奇幻 / 历史 / 科幻 / 言情…）
3. **人物与关系**（提供主角 / 对手 / 关键配角的核心设定）
4. **场景的目标情绪**（震撼 / 悲怆 / 喜悦 / 悬念 / 释然…）
5. **字数要求**（300字片段 / 1000字场景 / 完整一章）
6. **特殊要求**（如有金句、意象、对话风格的具体偏好）

skill 会按铁律顺序依次输出：结构骨架 → 人物刻画 → 场景模板 → 修辞打磨 → 减法检查 → 节奏控制 → 意象布置 → 金句收束。
