## 训练 3B：联缀法（短句合并）

把 5 个短句合并为 1 个长句。

**示范**：

```
原始 5 句：
他站在那里。他看着她。他的心跳加速。他的手心出汗。他想起了她。

合并：
他站在那里，看着她，心跳在胸腔里擂鼓一样地加速，手心渗出细密的汗珠，那一瞬间他想起了她——想起了她的笑、她说话的样子、她转身离开时的背影。
```

## 训练 3D：自查练习

写一段 500 字的场景（题材不限），然后用 python 检测句长分布：

```python
import re
text = '''把你的文字粘贴在这里'''
sents = [s for s in re.split(r'[。！？\n]', text) if s.strip()]
total = len(sents)
long_s = sum(1 for s in sents if len(s) > 50)
short_s = sum(1 for s in sents if len(s) < 15)
print(f"句长: >50字={long_s/total*100:.1f}% | <15字={short_s/total*100:.1f}%")
print(f"目标: >50字=15-20% | <15字=30-35%")
if long_s/total >= 0.15:
    print("✅ 长句比达标")
else:
    print(f"⚠️ 长句比不足，还缺 {(15 - long_s/total*100):.1f}% 的长句")
```
