# 训练 02：物象写心境（绝不直说情感）

> **对应模块**：03-修辞工厂（物象写心境）
> **原文参照**：references/02-物象写心境.md
> **核心原则**：永远不写"他很悲伤/愤怒/孤独"

---

## 练习 2A：为情感找物象

**差文**：他很孤独。

**江南式**：他坐在禁闭室里，只有一张孤零零的椅子和光滑的四壁。

**配对标**：

| 直白情感 | 找到的物象 |
|---------|-----------|
| 他很孤独 | 一张孤零零的椅子和光滑的四壁 |
| 她很绝望 | 像一朵渐渐干枯的小蘑菇 |
| 他怀念过去 | 偶然闻到故人的香水味，回头却只看见万千过客 |
| 父亲很爱他 | 男人笑得满脸开花，好像一点烦心事都没有似的 |

**练习**：为以下情感找到具体的物象（不能用抽象词）：

| 直白 | 你的物象 |
|------|---------|
| 他很紧张 | _____ |
| 她很悲伤 | _____ |
| 他很愤怒 | _____ |
| 他们很相爱 | _____ |
| 他很后悔 | _____ |

**规则**：物象必须具体到能画出来（"他很紧张"→"他的手在膝盖上反复摩挲，牛仔裤那块布料已经磨得发白"）。

## 练习 2B：用动作代替心理

**差文**（心理描写）→ 江南式（身体动作）：

| 差文 | 江南式 |
|------|--------|
| 他不想让继父发现他和生父还有联系 | 楚子航把来往的短信都删掉，给"爸爸"看到不好 |
| 他很悲伤 | 他轻轻地扣自己的胸口，想知道那里面的心是不是疼痛 |
| 他很想见到她 | 他掏出手机，输入短信，然后删掉，再输入，再删掉 |

**练习**：用身体动作改写以下心理描写：

> 他很想挽留她，但他知道没有资格。他只能看着她的背影消失在人海中。
